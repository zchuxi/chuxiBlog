# Live2D 看板娘拖动设计

## 目标

为桌面端 Miku 看板娘增加鼠标与触屏拖动能力。用户从模型展示区域开始拖动时，整个看板娘组件（模型及其操作按钮）同步移动；位置在刷新、重新加载模型和开关看板娘后保留。

## 交互约定

- 仅模型展示区域作为拖动手柄，操作按钮继续保持原有点击行为。
- 仅响应主指针；拖动开始后使用 Pointer Capture，指针移出模型区域仍可继续拖动。
- 拖动中显示 `grabbing` 光标并取消位移动画，释放或取消指针后恢复。
- 组件的可视占位（看板娘主体及外侧操作按钮）限制在浏览器可视区域内，并保留 8px 安全间距。
- 页面尺寸变化时重新约束当前位置，避免窗口缩小后组件留在屏幕外。
- 移动端当前隐藏看板娘，保留已保存的桌面端位置，不新增移动端展示行为。

## 架构

新增独立的 `live2dWidgetDrag.js`：

- 负责指针事件、边界计算、CSS 位移变量写入和 `localStorage` 持久化。
- 对外提供绑定函数，返回清理函数，便于 `LayoutView` 生命周期接入。
- 将边界计算保持为纯函数，便于 Node 测试覆盖。

`LayoutView.vue` 只负责：

- 持有看板娘根元素与舞台元素引用。
- 挂载后绑定拖动，卸载前解除绑定。
- 不改变 Live2D 模型加载、开关、水印参数和操作按钮业务。

## 数据与状态

- 使用独立存储键 `chuxi-live2d-position`。
- 保存 `{ "x": number, "y": number }`，分别映射到现有 CSS 变量 `--live2d-translate-x` 和 `--live2d-translate-y`。
- 无记录或记录非法时使用 `{ x: 0, y: 0 }`。
- 仅在拖动结束后写入存储，拖动过程中只更新视觉位置，减少同步写入。

## 异常与清理

- `localStorage` 不可用或数据损坏时静默回退默认位置。
- 元素缺失时绑定函数返回空清理函数，不影响页面加载。
- 清理时移除全部 Pointer 与 resize 监听，并释放残留拖动态。

## 验证

- 回归测试覆盖：位置约束、非法存储回退、拖动位移、释放后持久化、按钮区域不参与拖动、清理监听。
- 前端完整执行 `npm run lint`、`npm test`、`npm run build`。
- 若本地浏览器安全策略允许，再进行鼠标拖动与刷新后位置恢复的视觉验证。
